# parking_management_system
A simple Parking Management System written in C that allows users to manage two-wheeler and four-wheeler parking slots through a menu-driven console application.  📌 Features  - 🚘 Park a vehicle - 🗑️ Remove a parked vehicle - 🔍 Search for a parked vehicle - 📋 Display all currently parked vehicles in a table - 🅿️ Check available slots.
